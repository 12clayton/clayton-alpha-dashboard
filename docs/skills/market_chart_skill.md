# Market Chart Skill

## 目标

用图表解释市场状态，辅助判断是否过热、是否健康回踩、主攻方向是否强于基准、防守资产是否有效。

## 支持资产

- QQQ：纳指100。
- SMH：半导体。
- SOXX：半导体辅助。
- GLD：黄金ETF。
- GC=F：COMEX Gold Futures。
- SPY：标普500。
- UUP：美元。
- TLT：长期美债。

## 阶段收益率

必须支持：

- 1个月。
- 3个月。
- 6个月。
- YTD。
- 1年。
- 3年。
- 5年。

计算方式：

```text
period_return = 当前收盘价 / 周期起始收盘价 - 1
```

数据不足时显示“数据不足”。

## 归一化收益

归一化收益图起点为 100。

默认展示：

- QQQ。
- SMH。
- GLD。
- SPY。

目的：

- 看半导体是否跑赢纳指。
- 看纳指是否跑赢标普。
- 看黄金是否发挥防守作用。

## 技术指标

每个资产应尽量展示：

- K线或收盘价。
- 20日均线。
- 60日均线。
- RSI 14。
- 当前从近期高点回撤。

## 相对强弱

必须支持：

- SMH / QQQ。
- SOXX / QQQ。
- QQQ / SPY。
- GLD / SPY。

解释规则：

- SMH / QQQ 上升：半导体强于纳指。
- SOXX / QQQ 上升：半导体板块强于纳指。
- QQQ / SPY 上升：科技强于大盘。
- GLD / SPY 上升：防守资产强于股票。

## 图表边界

图表只用于解释市场状态，不生成买入金额。

最终动作仍由 `final_decision` 决定。

## Plotly key 规则

所有 `st.plotly_chart` 必须有唯一 key。

key 至少包含：

- 页面名。
- 分组名。
- ticker symbol。
- 图表类型。

如果 symbol 包含特殊字符，应先清洗：

```python
safe_symbol = symbol.replace("=", "_").replace("/", "_").replace("-", "_")
```

## 数据缺失规则

如果单个资产数据缺失：

- 跳过该资产。
- 显示“部分资产数据暂不可用，已跳过。”
- 不让整个页面崩溃。
