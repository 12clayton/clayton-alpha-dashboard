# Daily Decision Skill

## 目标

固定每日动作决策规则，避免不同页面、新闻模块、图表模块或行业研究模块各自生成冲突金额。

## 核心纪律

1. `final_decision` 是唯一今日动作来源。
2. 所有页面展示的今日金额、基金分配、是否动用灵活资金，都必须读取 `final_decision`。
3. 任何模块不得绕过 `final_decision` 独立生成买入金额。
4. 不自动交易，不连接券商账户，不生成强制买入/卖出指令。

## do_not_chase 一票否决

当系统进入 `do_not_chase`：

- 今日基础定投固定显示为 `¥60`。
- 不提高到 `¥80` 或 `¥100`。
- 不动用灵活资金。
- 灵活资金使用金额必须显示为 `¥0`。
- 新闻利好、行业主线增强、图表强势，都不能覆盖该纪律。

## 每日金额规则

- `¥60`：基础定投档，默认执行。
- `¥80`：健康回踩、小幅进攻档。
- `¥100`：较强回踩但未进入系统性风险时的最高日定投档。
- 每日固定定投不得超过 `¥100`。

## 灵活资金触发规则

灵活资金只在大机会时分批使用，不能一次性打满。

触发前必须同时检查：

- QQQ / SMH / SOXX 是否出现较大回撤。
- RSI 是否回到更合理区间。
- 中长期趋势是否未彻底破坏。
- 当前是否不是 `risk-off`。
- 当前是否不是 `do_not_chase`。
- 组合回撤是否未接近最大可接受阈值。

如果 `do_not_chase` 或 `defense_mode` 生效，灵活资金默认不动用。

## 黄金规则

黄金是防守缓冲，不是每日主攻定投。

- 黄金不计入每日 `¥60` 固定定投。
- 黄金补仓按两周计划单独观察。
- 黄金补仓不触发灵活资金。
- 黄金补仓金额不得改变 `final_decision.daily_dca_amount`。

## 新闻规则

新闻只能用于：

- 解释主线是否增强。
- 识别产业链机会。
- 提醒风险。
- 加入观察池。

新闻不能：

- 生成买入金额。
- 覆盖 `final_decision`。
- 覆盖 `do_not_chase`。
- 覆盖 `defense_mode`。

## 页面展示要求

所有涉及今日动作的页面必须清楚显示：

- 今日模式。
- 今日基础定投金额。
- 今日基金分配。
- 是否动用灵活资金。
- 黄金是否单独补仓。
- 今日纪律。
