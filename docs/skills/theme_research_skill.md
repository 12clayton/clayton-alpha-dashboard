# Theme Research Skill

## 目标

建立系统化行业研究框架，用于长期跟踪 Clayton 关注的主线。行业研究只做判断、解释、映射和观察，不直接生成买入金额。

## 支持主题

- 半导体。
- CPO / 光通信。
- CPU / ASIC / AI芯片。
- 存储 / HBM。
- AI算力 / 数据中心。
- SiC / GaN / 功率半导体。
- AI电力基础设施。
- 黄金 / 美元 / 实际利率。

## 每个主题固定结构

每个主题卡片必须包含：

1. 一句话 thesis。
2. 核心驱动因素。
3. 关键观察指标。
4. 产业链地图。
5. 我的基金映射。
6. 观察股票 / ETF。
7. 当前状态。
8. 评分。
9. 对今日动作的影响。

## Thesis

Thesis 要用一句话解释：

- 这个行业为什么值得长期关注。
- 它在 Clayton Alpha 框架里属于主攻、防守、观察池还是配套基础设施。

## 核心驱动

驱动因素应覆盖：

- 需求。
- 资本开支。
- 价格。
- 政策。
- 技术升级。
- 供需瓶颈。
- 估值和拥挤度。

## 关键观察指标

指标可以包括：

- ETF：QQQ、SMH、SOXX、GLD、TLT、UUP。
- 股票：NVDA、TSM、AVGO、AMD、MU、MRVL、CRDO、VRT、ETN、WOLF 等。
- 宏观变量：DFII10、美元、实际利率、美债收益率。

## 产业链地图

每个主题应拆成：

- 上游。
- 中游。
- 下游。
- 配套环节。

不要求真实持仓穿透，但必须说明产业链位置。

## 股票 / ETF / 基金映射

映射应区分：

- 我的基金。
- 观察股票。
- 观察 ETF。
- 主题方向。

public 模式可以展示主题和状态，但不展示真实持仓金额。

## 评分规则

每个主题给 1-5 分：

- 产业景气度。
- 市场趋势。
- 估值 / 拥挤度。
- 新闻质量。
- 我的组合匹配度。

评分用于排序和观察，不用于直接生成买入金额。

## 当前状态

允许状态：

- 主线增强。
- 健康回踩。
- 过热不追。
- 趋势走弱。
- 观察池。
- 防守观察。

## 今日动作影响

行业研究只能输出：

- 不改变今日定投。
- 只作为观察池。
- 健康回踩时可作为加速依据。
- 当前过热，不追高。
- 黄金按两周计划择时。

最终买入金额仍由 `final_decision` 决定。
