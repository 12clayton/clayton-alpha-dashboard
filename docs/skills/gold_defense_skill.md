# Gold Defense Skill

## 目标

黄金模块用于监控防守缓冲，不参与半导体 / CPO / CPU 主攻框架，不改变每日固定定投金额。

## 观察指标

必须跟踪：

- `GC=F`：COMEX Gold Futures，黄金期货价格温度计。
- `GLD`：SPDR Gold ETF，黄金ETF趋势代理。
- `UUP`：美元指数ETF，美元强弱代理。
- `TLT`：长期美债ETF，利率 / 防守资产代理。
- `DFII10`：美国10年期实际利率，黄金宏观压力指标。

如果 `DFII10` 不可用，应显示：

> 部分宏观数据缺失：DFII10 实际利率暂不可用；黄金判断已基于 GC=F、GLD、UUP 和当前黄金仓位生成。

## UUP 判断

UUP 需要按 RSI 单独解释：

- RSI > 70：`美元偏强 / dollar_strength_pressure`。
- RSI 45-60：`neutral`。
- RSI < 40：`dollar_weakness_supportive`。

美元偏强会压制黄金，因此黄金只小额补或等待，不追涨。

## gold_mode

允许模式：

### gold_accumulate

条件：

- 黄金仓位低于目标。
- GLD 或 GC=F 趋势不差。
- UUP 不明显走强。
- DFII10 没有明显上行。

动作：

- 两周补黄金默认 `¥60`。
- 回调明显时 `¥90-105`。

### gold_wait

条件：

- 黄金仓位仍低于目标。
- 但 GC=F / GLD 趋势偏弱，或美元偏强，或实际利率上行。

动作：

- 只允许小额防守补仓。
- 不追涨。
- 可显示 `¥30 或暂停一次`。

标准解释：

> 黄金仓位仍低于目标，但 GC=F 趋势偏弱或美元偏强，因此只允许小额防守补仓，不追涨。

### gold_hold

条件：

- 黄金仓位在 8%-10%。

动作：

- 维持，不额外加速。

### gold_pause

条件：

- 黄金仓位超过 10%。
- 或 GLD / GC=F RSI > 70。
- 或黄金短线过热。

动作：

- 暂停补仓。

## 黄金两周补仓

黄金按两周节奏检查，不每天重复提示补仓。

如果本轮已补，应显示：

> 本轮黄金补仓已执行，等待下一轮两周检查。

private 模式可以显示具体金额。

public 模式只显示状态，不显示真实金额。

## 与每日定投的关系

- 黄金不计入每日 `¥60` 固定定投。
- 黄金补仓不改变 `final_decision.daily_dca_amount`。
- 黄金补仓不触发灵活资金。
- 黄金模块只能影响黄金补仓观察，不能改变主攻仓金额。
