# Portfolio X-Ray Skill

## 目标

把多个 QDII / ETF联接基金近似穿透成投资模块，帮助理解组合真正暴露在哪里，而不是只看基金名称。

## 模块暴露

当前支持模块：

- 纳指科技核心。
- 半导体 / CPO / CPU / AI算力。
- 黄金。
- 标普500。
- 日经225。
- 其他。

## 当前 vs 目标

目标结构：

- 纳指科技核心：37%。
- 半导体 / CPO / CPU / AI算力：53%。
- 黄金：10%。
- 标普500：暂停新增。
- 日经225：暂停观察。

X-Ray 只输出偏离提示，不生成买入金额。

## 目标偏离

偏离提示应回答：

- 哪个模块低于目标。
- 哪个模块高于目标。
- 今天新增资金优先观察哪个模块。

“优先观察”不等于“自动买入”。

## 基金重叠提醒

如果多个基金都属于科技、AI、半导体、CPO、CPU 或纳指科技方向，应提示：

> 底层持仓可能高度重叠。

当前阶段按 `theme`、`proxy_symbol`、`role_in_portfolio` 近似分析，不要求真实穿透前十大持仓。

## public/private 展示规则

private 模式：

- 可以显示真实金额。
- 可以显示当前仓位和偏离。
- 可以显示基金映射。

public 模式：

- 不显示真实持仓金额。
- 不显示机动资金余额。
- 不显示本地路径。
- 可以显示比例、区间、状态和研究结论。

## 边界

Portfolio X-Ray 不得：

- 修改 `final_decision`。
- 生成今日买入金额。
- 自动交易。
- 连接券商账户。
